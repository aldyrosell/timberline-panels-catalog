# Timberline Panels

A laminates website with a filterable product catalogue, a sample-request cart and quote requests, run from an admin panel.

A demo app, like EcommerceApp and BookingApp: seeded sample content, reset every hour on the public demo.

**Status:** planning. The code here is still the original marketing site on Sanity. The plan to turn it
into the full app is in [docs_development/PLAN.md](docs_development/PLAN.md).
